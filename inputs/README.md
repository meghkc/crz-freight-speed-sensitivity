# Excluded inputs

This folder is the default location for the inputs that are not distributed with
the repository. Set `CRZ_INPUTS` to use another folder. Files keep the paths shown
below, relative to `CRZ_INPUTS`. Everything in this folder except this README is
ignored by git.

Derived from the proprietary freight assignment (available from the authors on
request, subject to the data owner's terms):

| Path | Contents | Needed by |
|---|---|---|
| `phase1b/qa/scenario_cells.csv` | Road x period x truck x road-class activity cells | Phase 1B, 2, 3, 5 |
| `phase1b/qa/physical_segments.csv` | Physical road keys and in-zone lengths | Phase 3, 5 |
| `phase1b/qa/baseline_activity.csv` | VMT by road class, period and truck type | Phase 1B, 2, 3, 5 |
| `phase1b/qa/legacy_replicates.csv` | Screening-model replicates and solved gains | Phase 1B, 2, 3, 5 |
| `phase1b/qa/paired_allocations.npz` | Random allocations (4 x 500 x 1,689 roads) | Phase 1B, 2, 3, 5 |
| `phase3/provenance/structured_allocations.npz` | Structured allocations (3 x 500 x 1,689 roads) | Phase 5 |
| `phase3/provenance/physical_segment_eligibility.csv` | Per-road VMT and structured-set membership | Reference only |

Needed only to rebuild the files above or to rerun Phase 3 and Phase 2R from scratch:
`data/` (the freight assignment, CRZ boundary and screening-model outputs),
`freight_model/` (the upstream NYC freight screening model) and
`phase2r/raw/attenuation_gap_cell_level.parquet` (regenerated by `code/phase2/repair_exports.py`).
